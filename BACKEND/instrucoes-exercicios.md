# Instruções para armazenar os exercícios desenvolvidos durante a aula

### Pré-requisitos

    - repositório criado no github (conforme criado nas aulas anteriores)
    - clone do repositório criado no github

### Onde encontrar os exercícios

    - Cada aula possui os seus próprios exercícios
    - Dentro do diretório da aula em questão, existirá um outro diretório, denominado `exercicios`
        Exemplo:
        Caso você esteja na aula 2, os exercícios estarão em:
        `aulas/02 - Metodos e Status HTTP/exercicios`

        *Algumas aulas não possuem exercícios de fixação`

### Como resolver os exercícios

    - Cada exercício pode possuir um conjunto de instruções própria, então basta seguir o que constar no exercício em questão
    - A maioria dos exercícios está descrita dentro de arquivos .js, contendo o espaço para resolução e podendo ser executado direto
    - Caso não possua um conjunto específico de instruções, siga esses passos

    1 - Abra no vscode o repositório que clonou na sua máquina (pré-requisito)
    2 - crie uma nova pasta dentro desse repositório, indicando de qual aula são os exercícios
    3 - crie um arquivo chamado "exercicio-1.js" (caso se trate do exercicios 2, o nome do arquivo seria "exercicio-2.js")
    *Importante ter a extensão .js*
    4 - Realize o que for proposto dentro da descrição do exercício

### Como fazer o envio da resolução

    - Se tratando de um repositório git, o envio **deve ser feito usando essa ferramenta**

    - ao terminar de desenvolver a solução do exercício, você deve enviar para o repositório remoto
        `git add`
        `git commit`
        git push <nome do repositório> <branch>

        *não se preocupe em criar branchs, a branch principal é suficiente e atende perfeitamente o que precisamos*
